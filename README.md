## Getting Started

### Prerequisites

Install the following tools before running the project:

- Java Development Kit (JDK)
- Maven, if the project does not include a Maven Wrapper
- MySQL Server
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/Rishi737-beep/HR-Managment-System.git
cd HR-Managment-System
```

### 2. Configure MySQL

Start MySQL and create the database required by the application.

```sql
CREATE DATABASE nexus_hr;
```

**Note:** `nexus_hr` is an example database name. Use the database name expected by the project's existing configuration.

Configure the database URL, username, and password in the application's local configuration. Do not commit real credentials or secrets to GitHub.

### 3. Run the Application

If the project contains a Maven `pom.xml`, navigate to its directory and run:

```bash
mvn spring-boot:run
```

If the repository includes a Maven Wrapper, use the appropriate wrapper command for your operating system.

Follow the application's configuration for the database connection and server port.
